# 📺 IPTV Pro Player
Siyah-Kırmızı temalı, kumanda destekli IPTV oynatıcı.

## Kaynaklar
- M3U: `room.coinmybook.workers.dev`
- Addon: `tvvoo.hayd.uk/cfg-tr/manifest.json`

## Kurulum
1. Android Studio'da açın
2. Gradle Sync yapın
3. Run

## Kumanda
| Tuş | İşlev |
|-----|-------|
| ▲▼ | Kanal değiştir |
| ◄ | Kanal listesi |
| ► | Hızlı menü |
| OK | Bilgi paneli |
| INFO | EPG rehber |
| 0-9 | Direkt kanal |
